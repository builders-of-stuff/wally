# Claude.md - Development Guidelines

## File Naming Conventions

### Use kebab-case for all filenames
- ✅ `post-card.svelte`
- ✅ `navigation.svelte`
- ✅ `user-profile.svelte`
- ❌ `PostCard.svelte`
- ❌ `Navigation.svelte`
- ❌ `UserProfile.svelte`

### Examples
- Components: `blog-header.svelte`, `comment-list.svelte`
- Services: `blog-service.ts`, `auth-service.ts`
- Types: `user-types.ts`, `blog-types.ts`
- Utils: `date-utils.ts`, `string-utils.ts`

## Project Structure
This is a public blog platform where anyone can contribute posts, built with SvelteKit, Sui blockchain, and Walrus storage.
